American Abundance Index

Interactive Visualization Example

About This Example: This standalone HTML file demonstrates how to load AAI data from the Excel file and create an interactive D3.js chart. The code is fully commented to help you understand each step and adapt it for your own visualizations.
Instructions:
  1. Download the latest AAI Excel file from the data/processed/ folder
  2. Place it in the same directory as this HTML file
  3. Update the filename on line 206 if your file has a different name
  4. Open this file in a web browser (may need to run a local server)
  5. Hover over the chart to see data values
To customize this example:
• Change EXCEL_FILE on line 206 to match your data file
• Change VIEW on line 209 to show different worker categories
• Change METRIC on line 212 to show different metrics
• Modify WIDTH and HEIGHT on lines 215-216 for sizing
• Adjust COLORS on lines 219-224 for different styling
